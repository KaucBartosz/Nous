Uwaga: System Windows ochronił ten komputer

System Windows (SmartScreen) może zablokować uruchomienie ponieważ aplikacja jest nowa. Aby zainstalować:

1. Kliknij "Więcej informacji".
2. Kliknij "Uruchom mimo to".

Pobierz dla macOS

Pobierz plik .dmg

Przy pierwszym uruchomieniu

System macOS (Gatekeeper) może zablokować aplikację, ponieważ pochodzi od "niezidentyfikowanego dewelopera".

1. Otwórz folder Aplikacje.
2. Kliknij prawym przyciskiem myszy na "Nous" i wybierz "Otwórz".

Pobierz dla Linux

Pobierz plik .AppImage

Jak uruchomić w terminalu:

terminal

$ chmod +x Nous*.AppImage

$ ./Nous*.AppImage

Skoro używasz linuxa to na pewno sobie poradzisz! 🐧
